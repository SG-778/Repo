# Additional (Second chance) — Text stats, Normalization, Expenses Parser

This repo contains three learning tasks implemented in **`Second chance.py`**:

- **Task A — `text_stats(s)`**: count characters, words, lowercase, uppercase, digits.
- **Task B — `normalize_spaces(s)`, `strip_punctuation(s)`**: tidy text for later analysis.
- **Task C — `parse_expenses(lines)`**: parse CSV-like lines `YYYY-MM-DD,category,amount` and sum amounts per category.


---

## Files & folders
- `Second chance.py` — main script with all three tasks and small demos.
- `Class.py`, `Hello_world.py`, `Never_give_up.py` — other practice files.
- `.gitignore` — ignores caches/venv, etc.
- `.idea/` — PyCharm project files.
